## 问题分析

### 当前问题

#### 1. 数据库名称不一致
- **AI-Service**: 使用 `synapsetest`
- **Backend**: 使用 `test_management`
- ❌ **问题**: 两个服务使用不同的数据库，导致数据无法共享

#### 2. test_cases表定义冲突

**AI-Service版本** (`ai-service/scripts/init_mysql.sql`):
```sql
CREATE TABLE test_cases (
  id VARCHAR(50) PRIMARY KEY,
  name VARCHAR(200) NOT NULL,
  module VARCHAR(100),
  priority ENUM('P0', 'P1', 'P2', 'P3'),
  type VARCHAR(50),
  preconditions JSON,
  steps JSON,
  tags JSON,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  created_by VARCHAR(50),
  quality_score FLOAT
);
```

**Backend版本** (`backend/src/main/resources/schema.sql`):
```sql
CREATE TABLE test_cases (
  id CHAR(36) PRIMARY KEY DEFAULT (UUID()),
  title VARCHAR(200) NOT NULL,
  description TEXT,
  steps JSON NOT NULL,
  expected_result TEXT,
  priority INTEGER DEFAULT 0,
  type VARCHAR(20) NOT NULL CHECK (type IN ('FUNCTIONAL', 'PERFORMANCE', 'SECURITY')),
  status VARCHAR(20) NOT NULL CHECK (status IN ('DRAFT', 'APPROVED', 'DEPRECATED')),
  tags JSON,
  related_requirement VARCHAR(200),
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  created_by VARCHAR(100) NOT NULL
);
```

**字段差异**:
| 字段名 | AI-Service | Backend | 冲突 |
|--------|-----------|---------|------|
| id | VARCHAR(50) | CHAR(36) UUID | ⚠️ 长度和类型不同 |
| name/title | name VARCHAR(200) | title VARCHAR(200) | ⚠️ 字段名不同 |
| module | ✅ 有 | ❌ 无 | ⚠️ AI独有 |
| description | ❌ 无 | ✅ 有 | ⚠️ Backend独有 |
| preconditions | ✅ 有 (JSON) | ❌ 无 | ⚠️ AI独有 |
| expected_result | ❌ 无 | ✅ 有 (TEXT) | ⚠️ Backend独有 |
| priority | ENUM('P0','P1','P2','P3') | INTEGER 0-10 | ⚠️ 类型完全不同 |
| status | ❌ 无 | ✅ 有 | ⚠️ Backend独有 |
| quality_score | ✅ 有 (FLOAT) | ❌ 无 | ⚠️ AI独有 |
| updated_at | ❌ 无 | ✅ 有 | ⚠️ Backend独有 |

#### 3. Backend schema.sql存在重复定义

**重复定义的表**:
- `monitoring_data` (定义了2次: line 8-30, line 161-182)
- `ai_model` vs `ai_models` (定义了2次: line 145-158, line 185-200)
- `quality_report` vs `quality_reports` (定义了2次，结构不同)

## 合并策略

### 总体原则

1. **以Backend为主**: Backend是核心服务，其表结构更完整
2. **保留AI特性**: AI-Service独有的历史记录表必须保留
3. **修复重复**: 清理Backend schema.sql的重复定义
4. **统一命名**: 统一数据库名为 `synapsetest`
5. **兼容性优先**: 尽量保持现有代码的兼容性

### 具体策略

#### 1. 数据库名称
- **统一为**: `synapsetest`
- **理由**: AI-Service使用此名称，且更简洁

#### 2. test_cases表
- **采用Backend的结构为基础**
- **增加AI-Service需要的字段**:
  - `module` VARCHAR(100) - 所属模块
  - `preconditions` JSON - 前置条件
  - `quality_score` FLOAT - AI质量评分
  - `ai_generated` BOOLEAN - 是否AI生成
  - `ai_confidence` FLOAT - AI置信度

#### 3. 添加AI独有表
将以下表添加到统一schema:
- `generation_history` (重命名为 `testcase_generation_history`)
- `recommendation_history`
- `user_feedback`
- `company_standards`

#### 4. 修复Backend重复定义
- 删除重复的 `monitoring_data` 定义
- 统一为 `ai_models` (删除 `ai_model`)
- 统一为 `quality_reports` (删除 `quality_report`)

## 统一表结构定义

### 核心表结构

#### 1. test_cases (测试用例表) - 合并版本

```sql
CREATE TABLE IF NOT EXISTS test_cases (
    -- 基础字段 (Backend)
    id CHAR(36) PRIMARY KEY DEFAULT (UUID()) COMMENT '用例ID',
    title VARCHAR(200) NOT NULL COMMENT '用例标题',
    description TEXT COMMENT '用例描述',
    steps JSON NOT NULL COMMENT '测试步骤',
    expected_result TEXT COMMENT '预期结果',

    -- 分类字段 (Backend + AI-Service)
    module VARCHAR(100) COMMENT '所属模块',
    type VARCHAR(20) NOT NULL CHECK (type IN ('FUNCTIONAL', 'PERFORMANCE', 'SECURITY')) COMMENT '测试类型',
    priority INTEGER DEFAULT 0 CHECK (priority >= 0 AND priority <= 10) COMMENT '优先级(0-10)',
    status VARCHAR(20) NOT NULL DEFAULT 'DRAFT' CHECK (status IN ('DRAFT', 'APPROVED', 'DEPRECATED')) COMMENT '状态',
    tags JSON COMMENT '标签',
    related_requirement VARCHAR(200) COMMENT '关联需求',

    -- AI增强字段 (AI-Service)
    preconditions JSON COMMENT '前置条件',
    quality_score FLOAT DEFAULT 0.0 COMMENT 'AI质量评分(0.0-1.0)',
    ai_generated BOOLEAN DEFAULT FALSE COMMENT '是否AI生成',
    ai_confidence FLOAT DEFAULT 0.0 COMMENT 'AI置信度(0.0-1.0)',

    -- 审计字段
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    created_by VARCHAR(100) NOT NULL COMMENT '创建人',

    -- 索引
    INDEX idx_module (module),
    INDEX idx_type (type),
    INDEX idx_priority (priority),
    INDEX idx_status (status),
    INDEX idx_ai_generated (ai_generated),
    INDEX idx_created_at (created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='测试用例表(Backend+AI统一)';
```

#### 2. testcase_generation_history (测试用例生成历史)

```sql
CREATE TABLE IF NOT EXISTS testcase_generation_history (
    id CHAR(36) PRIMARY KEY DEFAULT (UUID()) COMMENT '记录ID',

    num_cases_generated INT COMMENT '实际生成数量',
    generation_time_ms BIGINT COMMENT '生成耗时(毫秒)',
    llm_provider VARCHAR(50) COMMENT 'LLM提供商',
    model_name VARCHAR(100) COMMENT '模型名称',
    success BOOLEAN DEFAULT TRUE COMMENT '是否成功',
    error_message TEXT COMMENT '错误信息',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',

    INDEX idx_user_id (user_id),
    INDEX idx_module (module),
    INDEX idx_created_at (created_at),
    INDEX idx_success (success)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='测试用例生成历史';
```

#### 3. recommendation_history (策略推荐历史)

```sql
CREATE TABLE IF NOT EXISTS recommendation_history (
    id CHAR(36) PRIMARY KEY DEFAULT (UUID()) COMMENT '记录ID',
    task_id VARCHAR(50) COMMENT '任务ID',
    environment_id VARCHAR(50) COMMENT '环境ID',
    version_id VARCHAR(50) COMMENT '版本ID',
    recommendation JSON NOT NULL COMMENT '推荐结果',
    risk_assessment JSON COMMENT '风险评估',
    context JSON COMMENT '上下文信息',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',

    INDEX idx_task_id (task_id),
    INDEX idx_environment_id (environment_id),
    INDEX idx_version_id (version_id),
    INDEX idx_created_at (created_at),

    FOREIGN KEY (environment_id) REFERENCES test_environments(id) ON DELETE SET NULL,
    FOREIGN KEY (version_id) REFERENCES test_versions(id) ON DELETE SET NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='策略推荐历史';
```

#### 4. user_feedback (用户反馈)

```sql
CREATE TABLE IF NOT EXISTS user_feedback (
    id CHAR(36) PRIMARY KEY DEFAULT (UUID()) COMMENT '反馈ID',
    request_id VARCHAR(50) COMMENT '生成请求ID',

    INDEX idx_rating (rating),
    INDEX idx_feedback_type (feedback_type),
    INDEX idx_user_id (user_id),
    INDEX idx_created_at (created_at),

    FOREIGN KEY (request_id) REFERENCES testcase_generation_history(request_id) ON DELETE SET NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='用户反馈表';

) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='公司测试标准';

                test_case.get('description', ''),
                json.dumps(test_case.get('steps', []), ensure_ascii=False),
                test_case.get('expected_result') or test_case.get('expected_results', ''),
                test_case.get('module'),
                test_case.get('type', 'FUNCTIONAL'),
                self._convert_priority(test_case.get('priority', 5)),  # 转换为0-10
                test_case.get('status', 'DRAFT'),
                json.dumps(test_case.get('tags', []), ensure_ascii=False),
                json.dumps(test_case.get('preconditions', []), ensure_ascii=False),
                test_case.get('quality_score', 0.0),
                test_case.get('ai_generated', True),
                test_case.get('ai_confidence') or test_case.get('confidence', 0.0),
                test_case.get('related_requirement', ''),
                test_case.get('created_by', 'ai-service')
            ))

            conn.commit()
            logger.info(f"测试用例保存成功: {test_case.get('title')}")
            return True
        except Exception as e:
            conn.rollback()
            logger.error(f"保存测试用例失败: {e}")
            return False
        finally:
            cursor.close()

def _convert_priority(self, priority):
    """
    转换优先级格式
    AI-Service: 'P0', 'P1', 'P2', 'P3' 或 1-10
    Backend: 0-10 INTEGER
    """
    if isinstance(priority, str):
        if priority.startswith('P'):
            # P0 -> 10, P1 -> 8, P2 -> 5, P3 -> 3
            mapping = {'P0': 10, 'P1': 8, 'P2': 5, 'P3': 3}
            return mapping.get(priority, 5)
    return int(priority) if isinstance(priority, (int, float)) else 5
```
