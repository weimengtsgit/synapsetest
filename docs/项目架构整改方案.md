## 二、问题1: 接口调用架构优化

### 2.1 现状分析

#### Backend接口重复性分析

| 功能模块 | Backend接口 | AI-Service接口 | 重复情况 |
|---------|------------|----------------|---------|
| **测试用例生成** | `POST /api/v1/test-cases/generate` | `POST /api/v1/ai/testcase/generate` | ⚠️ **功能重复** |
| **测试用例去重** | `POST /api/v1/test-cases/deduplicate` | `POST /api/v1/ai/testcase/optimize/deduplicate` | ⚠️ **功能重复** |
| **测试用例优先级排序** | - | `POST /api/v1/ai/testcase/optimize/prioritize` | ❌ Backend缺失 |
| **测试策略推荐** | `POST /api/v1/test-tasks/ai/recommendation` | `POST /api/v1/ai/recommendation/strategy` | ⚠️ **功能重复** |
| **测试用例质量分析** | `POST /api/v1/test-cases/analyze-coverage` | `POST /api/v1/ai/testcase/analyze/quality` | ⚠️ **功能重复** |

**重复率**: 5/7 AI功能存在接口重复 (71%)

#### Frontend调用关系分析

**当前实现**:
```
Frontend (localhost:3000)
    │
    └─> Vite Proxy (/api → localhost:8080)
            │
            └─> Backend (localhost:8080)
                    │
                    └─> [配置了ai-service URL但未实际调用]
```

**关键问题**:
1. ✅ Frontend只调用Backend,架构清晰
2. ❌ Backend配置了ai-service URL但没有HTTP客户端实现
3. ⚠️ Backend的AI功能是本地规则引擎,不是真正的AI
4. ⚠️ AI-Service直接操作Backend的MySQL test_cases表(共享数据库)

### 2.2 推荐架构方案

#### 方案A: API网关模式 (推荐 ⭐⭐⭐⭐⭐)

```
Frontend (localhost:3000)
    │
    ├─> /api/v1/test-tasks/*      ──────> Backend (localhost:8080)
    ├─> /api/v1/test-cases/*      ──────> Backend (localhost:8080)
    ├─> /api/v1/test-environments/* ───> Backend (localhost:8080)
    ├─> /api/v1/test-versions/*   ──────> Backend (localhost:8080)
    ├─> /api/v1/monitoring/*      ──────> Backend (localhost:8080)
    ├─> /api/v1/reports/*         ──────> Backend (localhost:8080)
    │
    └─> /api/v1/ai/*              ──────> Backend (localhost:8080)
                                                │
                                                └─> AI-Service (localhost:8000)
                                                    [HTTP调用]
```

**优点**:
- ✅ Frontend单一入口,认证统一管理
- ✅ Backend作为业务网关,控制AI服务调用策略
- ✅ 易于实施流量控制、限流、熔断
- ✅ AI服务故障不影响基础功能

**缺点**:
- ⚠️ Backend增加HTTP调用开销 (~50-100ms)
- ⚠️ 需要维护AI服务的健康检查

#### 方案B: 前端直连模式 (不推荐 ⭐⭐)

```
Frontend
    ├─> /api/v1/test-* ──> Backend (localhost:8080)
    └─> /api/v1/ai/*   ──> AI-Service (localhost:8000)
```

**优点**:
- ✅ 性能最优,无代理开销
- ✅ 架构简单直接

**缺点**:
- ❌ 前端需要管理两套认证
- ❌ CORS配置复杂
- ❌ 安全性降低,AI服务直接暴露
- ❌ 无法统一限流和监控

```java
@Component
public class AIServiceClient {

    @Value("${services.ai-service.url}")

    private final RestTemplate restTemplate;

        this.restTemplate = builder
```

```java
@Service
public class AITestCaseGenerationService {

    @Autowired
    private AIServiceClient aiServiceClient;

    @Autowired
    private TestCaseService testCaseService;

    public AITestCaseGenerationResponse generateFromRequirement(AITestCaseGenerationRequest request) {
        try {
            // 调用AI-Service
            AITestCaseGenerationResponse response = aiServiceClient.generateTestCases(request);

            // 将AI生成的用例保存到Backend数据库
            for (GeneratedTestCase generatedCase : response.getGeneratedCases()) {
                TestCase testCase = convertToTestCase(generatedCase);
                testCaseService.createTestCase(testCase);
            }

            return response;
        } catch (Exception e) {
            log.error("AI服务调用失败: {}", e.getMessage());
            // 降级策略: 返回友好错误信息
            throw new AIServiceUnavailableException("AI服务暂时不可用,请稍后重试");
        }
    }

    private TestCase convertToTestCase(GeneratedTestCase generatedCase) {
        // 转换AI生成的用例格式到Backend格式
        TestCase testCase = new TestCase();
        testCase.setTitle(generatedCase.getName());
        testCase.setDescription(generatedCase.getDescription());
        testCase.setSteps(generatedCase.getSteps());
        testCase.setExpectedResult(generatedCase.getExpectedResult());
        testCase.setPriority(convertPriority(generatedCase.getPriority()));
        testCase.setType(convertType(generatedCase.getType()));
        return testCase;
    }
}
```

### 2.5 代码示例: 熔断和重试机制

**添加依赖** (backend/pom.xml):
```xml
<dependency>
    <groupId>io.github.resilience4j</groupId>
    <artifactId>resilience4j-spring-boot2</artifactId>
    <version>2.0.2</version>
</dependency>
```

**配置** (application.yml):
```yaml
resilience4j:
  circuitbreaker:
    instances:
      aiService:
        failure-rate-threshold: 50
        wait-duration-in-open-state: 30s
        sliding-window-size: 10
  retry:
    instances:
      aiService:
        max-attempts: 3
        wait-duration: 1s
```

**使用熔断器**:
```java
@Service
public class AITestCaseGenerationService {

    @Autowired
    private AIServiceClient aiServiceClient;

    @CircuitBreaker(name = "aiService", fallbackMethod = "generateFallback")
    @Retry(name = "aiService")
    public AITestCaseGenerationResponse generateFromRequirement(AITestCaseGenerationRequest request) {
        return aiServiceClient.generateTestCases(request);
    }

    /**
     * 降级方法: AI服务不可用时的处理
     */
    private AITestCaseGenerationResponse generateFallback(AITestCaseGenerationRequest request, Exception e) {
        log.warn("AI服务不可用,使用降级策略: {}", e.getMessage());

        AITestCaseGenerationResponse response = new AITestCaseGenerationResponse();
        response.setSuccess(false);
        response.setMessage("AI服务暂时不可用,请稍后重试或使用手动创建功能");
        response.setGeneratedCases(Collections.emptyList());

        return response;
    }
}
```

**实现**:

```python
# ai-service/services/recommendation_service.py

import requests
from typing import Optional
from config import config

class RecommendationService:

    def __init__(self):
        self.backend_url = config.BACKEND_URL  # http://localhost:8080

    def get_recommendation(self, request: RecommendationRequest):
        """获取测试策略推荐"""

        # 1. 从Backend获取环境信息
        environment = None
        if request.environment_id:
            environment = self._get_environment(request.environment_id)

        # 2. 从Backend获取版本信息
        version = None
        if request.version_id:
            version = self._get_version(request.version_id)

        # 3. 基于环境和版本调整推荐策略
        recommendation = self._calculate_recommendation(
            request.context,
            environment,
            version
        )

        return recommendation

    def _get_environment(self, env_id: str) -> Optional[dict]:
        """从Backend获取环境信息"""
        try:
            url = f"{self.backend_url}/api/v1/test-environments/{env_id}"
            response = requests.get(url, timeout=5)
            response.raise_for_status()
            return response.json()['data']
        except Exception as e:
            logger.warning(f"无法获取环境信息: {e}")
            return None

    def _get_version(self, version_id: str) -> Optional[dict]:
        """从Backend获取版本信息"""
        try:
            url = f"{self.backend_url}/api/v1/test-versions/{version_id}"
            response = requests.get(url, timeout=5)
            response.raise_for_status()
            return response.json()['data']
        except Exception as e:
            logger.warning(f"无法获取版本信息: {e}")
            return None

    def _calculate_recommendation(
        self,
        context: RecommendationContext,
        environment: Optional[dict],
        version: Optional[dict]
    ) -> dict:
        """基于环境和版本的推荐策略"""

        # 默认配置
        base_scope = 'CORE'
        risk_threshold = 0.5
        priority_boost = 0

        # 根据环境类型调整测试范围
        if environment:
            env_name = environment.get('name', '').upper()

            if env_name == 'PROD':
                base_scope = 'FULL'
                risk_threshold = 0.3  # 低容忍度
            elif env_name == 'STAGING':
                base_scope = 'CORE'
                risk_threshold = 0.5
            elif env_name == 'DEV':
                base_scope = 'SMOKE'
                risk_threshold = 0.7  # 高容忍度

            # 根据环境配置调整
            env_config = environment.get('config', {})
            if env_config.get('is_critical'):
                priority_boost += 2

        # 根据版本变更历史调整优先级
        if version:
            version_name = version.get('name', '')

            # 大版本升级 (如 1.0.0 -> 2.0.0)
            if self._is_major_release(version_name):
                priority_boost += 2
                base_scope = 'FULL'

            # 版本描述包含"hotfix"或"紧急"
            description = version.get('description', '').lower()
            if 'hotfix' in description or '紧急' in description:
                priority_boost += 3
                risk_threshold = 0.2

        # 计算最终推荐
        recommendation = {
            'test_scope': base_scope,
            'environment': environment['name'] if environment else 'DEV',
            'priority': self._calculate_priority(context, priority_boost),
            'estimated_duration': self._estimate_duration(base_scope),
            'risk_level': self._assess_risk(context, risk_threshold),
            'reasoning': self._generate_reasoning(
                base_scope, environment, version, context
            )
        }

        return recommendation

    def _is_major_release(self, version_name: str) -> bool:
        """判断是否为大版本发布"""
        # 简单的版本号解析
        parts = version_name.split('.')
        if len(parts) >= 2:
            major = int(parts[0])
            return major >= 2  # 2.0.0及以上视为大版本
        return False

    def _calculate_priority(self, context: RecommendationContext, boost: int) -> int:
        """计算优先级"""
        base_priority = 5

        # 根据代码变更调整
        if context.code_change:
            if context.code_change.changed_files_count > 20:
                base_priority += 2
            elif context.code_change.changed_files_count > 10:
                base_priority += 1

        # 根据历史数据调整
        if context.historical:
            if context.historical.recent_pass_rate < 0.8:
                base_priority += 2
            if context.historical.recent_defect_count > 5:
                base_priority += 1

        # 根据业务优先级调整
        if context.business:
            if context.business.module_importance > 0.8:
                base_priority += 2
            elif context.business.module_importance > 0.6:
                base_priority += 1

        # 应用boost
        final_priority = min(10, max(1, base_priority + boost))
        return final_priority

    def _estimate_duration(self, test_scope: str) -> int:
        """估算执行时长(分钟)"""
        duration_map = {
            'SMOKE': 10,
            'CORE': 60,
            'FULL': 180
        }
        return duration_map.get(test_scope, 60)

    def _assess_risk(self, context: RecommendationContext, threshold: float) -> str:
        """评估风险等级"""
        risk_score = 0.0

        # 代码变更风险
        if context.code_change:
            risk_score += context.code_change.changed_files_count * 0.01
            risk_score += context.code_change.changed_lines_count * 0.0005

        # 历史数据风险
        if context.historical:
            risk_score += (1 - context.historical.recent_pass_rate) * 0.3
            risk_score += context.historical.recent_defect_count * 0.05

        # 根据阈值判断
        if risk_score > threshold + 0.2:
            return 'HIGH'
        elif risk_score > threshold:
            return 'MEDIUM'
        else:
            return 'LOW'

    def _generate_reasoning(
        self,
        test_scope: str,
        environment: Optional[dict],
        version: Optional[dict],
        context: RecommendationContext
    ) -> list:
        """生成推荐理由"""
        reasoning = []

        if environment:
            env_name = environment.get('name', 'DEV')
            reasoning.append(
                f"环境为{env_name},推荐{'全量回归' if env_name=='PROD' else '核心' if env_name=='STAGING' else '冒烟'}测试"
            )

        if version:
            version_name = version.get('name', '')
            if self._is_major_release(version_name):
                reasoning.append(f"版本{version_name}为大版本升级,建议全面测试")
            else:
                reasoning.append(f"版本{version_name}为小版本升级,风险可控")

        if context.code_change and context.code_change.changed_files_count > 10:
            reasoning.append(
                f"代码变更较大({context.code_change.changed_files_count}个文件),建议扩大测试范围"
            )

        if context.historical and context.historical.recent_pass_rate < 0.9:
            reasoning.append(
                f"最近通过率较低({context.historical.recent_pass_rate*100:.1f}%),建议增加测试覆盖"
            )

        return reasoning
```

```tsx
function generateTrendData() {
  const days = 7;
  const data = [];
  const types = ['生成用例数', '通过率'];

  for (let i = days - 1; i >= 0; i--) {
    const date = new Date();
    date.setDate(date.getDate() - i);
    const dateStr = `${date.getMonth() + 1}/${date.getDate()}`;

    types.forEach(type => {
      data.push({
        date: dateStr,
        type,
        value: type === '生成用例数' ?
          Math.floor(Math.random() * 50 + 100) :
          Math.floor(Math.random() * 10 + 85)
      });
    });
  }

  return data;
}
```

**批量生成页面示例** (frontend/src/components/test-case/BatchGenerate.tsx):

```tsx
import React, { useState } from 'react';
import { Form, Input, Button, Upload, Table, message, Card, InputNumber } from 'antd';
import { UploadOutlined, PlusOutlined } from '@ant-design/icons';
import { aiService } from '../../services/aiService';

export const BatchGenerate: React.FC = () => {
  const [form] = Form.useForm();
  const [requirements, setRequirements] = useState([]);
  const [loading, setLoading] = useState(false);
  const [results, setResults] = useState([]);

  const handleUpload = (file: File) => {
    // 解析Excel文件
    const reader = new FileReader();
    reader.onload = (e) => {
      // 解析Excel数据
      // 这里需要集成xlsx库
      const reqs = parseExcelData(e.target.result);
      setRequirements(reqs);
      message.success(`导入 ${reqs.length} 条需求`);
    };
    reader.readAsArrayBuffer(file);
    return false;
  };

  const handleAddRequirement = () => {
    setRequirements([
      ...requirements,
      {
        id: Date.now(),
        module: '',
        requirement: '',
      },
    ]);
  };

  const handleBatchGenerate = async (values: any) => {
    if (requirements.length === 0) {
      message.warning('请先添加需求');
      return;
    }

    setLoading(true);
    try {
      const requests = requirements.map(req => ({
        requirement_text: req.requirement,
        module: req.module,
        num_cases: values.numCases || 5,
        include_edge_cases: values.includeEdgeCases,
      }));

      const response = await aiService.batchGenerate({ requests });

      if (response.success) {
        setResults(response.data.results);
        message.success(`批量生成完成,共生成 ${response.data.total_cases} 条用例`);
      }
    } catch (error) {
      message.error('批量生成失败: ' + error.message);
    } finally {
      setLoading(false);
    }
  };

  return (
    <div>
      <Card title="批量生成测试用例">
        <Form form={form} layout="vertical" onFinish={handleBatchGenerate}>
          <Form.Item label="导入需求文件">
            <Upload beforeUpload={handleUpload} accept=".xlsx,.xls" maxCount={1}>
              <Button icon={<UploadOutlined />}>上传Excel文件</Button>
            </Upload>
          </Form.Item>

          <Form.Item label="需求列表">
            <Button icon={<PlusOutlined />} onClick={handleAddRequirement}>
              手动添加需求
            </Button>
            <Table
              dataSource={requirements}
              columns={[
                { title: '模块', dataIndex: 'module', key: 'module' },
                { title: '需求描述', dataIndex: 'requirement', key: 'requirement' },
              ]}
              pagination={false}
              style={{ marginTop: 16 }}
            />
          </Form.Item>

          <Form.Item label="每个需求生成用例数" name="numCases" initialValue={5}>
            <InputNumber min={1} max={20} />
          </Form.Item>

          <Form.Item>
            <Button type="primary" htmlType="submit" loading={loading}>
              批量生成
            </Button>
          </Form.Item>
        </Form>

        {results.length > 0 && (
          <div style={{ marginTop: 24 }}>
            <h3>生成结果</h3>
            <Table
              dataSource={results}
              columns={[
                { title: '模块', dataIndex: 'module' },
                { title: '生成数量', dataIndex: 'count' },
                { title: '状态', dataIndex: 'status' },
              ]}
            />
          </div>
        )}
      </Card>
    </div>
  );
};
```
