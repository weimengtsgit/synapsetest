# 数据库表结构合并快速执行指南

> **本指南提供数据库合并的快速执行步骤**
> 详细方案请参考: [数据库表结构合并方案.md](./数据库表结构合并方案.md)

---

## 📊 问题总结

### 发现的问题

1. **❌ 数据库名称不一致**
   - AI-Service使用: `synapsetest`
   - Backend使用: `test_management`

2. **❌ test_cases表定义冲突**
   - 字段名不同: `name` vs `title`
   - 字段类型不同: 优先级 `ENUM('P0','P1','P2','P3')` vs `INTEGER 0-10`
   - AI独有字段: `quality_score`, `preconditions`
   - Backend独有字段: `description`, `expected_result`, `status`

3. **❌ Backend schema.sql重复定义**
   - `monitoring_data` 定义了2次
   - `ai_model` vs `ai_models` 定义了2次
   - `quality_report` vs `quality_reports` 定义了2次

4. **✅ AI-Service独有表** (需要保留)
   - `generation_history` - 用例生成历史
   - `recommendation_history` - 策略推荐历史
   - `user_feedback` - 用户反馈
   - `company_standards` - 公司标准

---

## 🎯 解决方案

### 核心策略

1. **统一数据库名**: 使用 `synapsetest`
2. **以Backend为主**: Backend的表结构更完整
3. **保留AI特性**: 添加AI独有的表和字段
4. **修复重复**: 清理Backend重复定义

## 🚀 快速执行步骤

### 步骤1: 备份现有数据 (必须!)

```bash
# 备份AI-Service数据库
mysqldump -u root -p synapsetest > ~/backup/synapsetest_backup_$(date +%Y%m%d_%H%M%S).sql

# 备份Backend数据库
mysqldump -u root -p test_management > ~/backup/test_management_backup_$(date +%Y%m%d_%H%M%S).sql
```

### 步骤2: 执行统一Schema

```bash
# 进入项目目录
cd /Users/mengwei/ww/github/synapsetest

# 执行统一Schema (会创建synapsetest数据库)
mysql -u root -p < database/unified_schema.sql
```

**验证**:
```sql

```

### 步骤3: 更新Backend配置

**修改文件**: `backend/src/main/resources/application.yml`

```yaml
spring:
  datasource:
    # 修改前: jdbc:mysql://localhost:3306/test_management
    url: jdbc:mysql://localhost:3306/synapsetest?useSSL=false&serverTimezone=UTC
    username: root
    password: password
```

**替换schema文件**:
```bash
# 备份旧版本
cp backend/src/main/resources/schema.sql backend/src/main/resources/schema.sql.bak

# 使用统一版本
cp database/unified_schema.sql backend/src/main/resources/schema.sql
```

### 步骤4: 更新AI-Service配置

**修改文件**: `ai-service/.env`

```bash
# 数据库配置
MYSQL_DATABASE=synapsetest  # 确保使用synapsetest
MYSQL_HOST=localhost
MYSQL_PORT=3306
MYSQL_USER=root
MYSQL_PASSWORD=password
```

**统一MySQL客户端**:
```bash
cd ai-service/data

# 1. 备份现有文件
cp mysql_client.py mysql_client_old.py

# 2. 使用统一版本
cp mysql_client_unified_backend.py mysql_client.py

# 3. 删除多余文件
rm mysql_client_unified.py
rm mysql_client_unified_backend.py
```

### 步骤5: 更新AI-Service init_mysql.sql

**替换文件**: `ai-service/scripts/init_mysql.sql`

```bash
# 备份旧版本
cp ai-service/scripts/init_mysql.sql ai-service/scripts/init_mysql.sql.bak

# 使用统一版本
cp database/unified_schema.sql ai-service/scripts/init_mysql.sql
```

### 步骤6: 运行测试验证

```bash

mvn clean test

# AI-Service测试
cd ai-service
pytest tests/ -v

```

## 📝 test_cases表字段对照

### 旧版本字段映射

| AI-Service旧字段 | 统一版本字段 | 转换说明 |
|-----------------|------------|---------|
| `name` | `title` | 直接映射 |
| - | `description` | 新增，默认空 |
| `module` | `module` | 保留 |
| `priority` ENUM | `priority` INT | P0→10, P1→8, P2→5, P3→3 |
| `preconditions` | `preconditions` | 保留 |
| `quality_score` | `quality_score` | 保留 |
| - | `ai_generated` | 新增，默认TRUE |
| - | `ai_confidence` | 新增，使用confidence值 |
| - | `status` | 新增，默认'DRAFT' |

### 优先级转换规则

```python
# AI-Service代码中添加转换函数
def convert_priority(old_priority):
    """
    AI-Service: 'P0', 'P1', 'P2', 'P3'
    Backend: 0-10 INTEGER
    """
    if isinstance(old_priority, str):
        mapping = {'P0': 10, 'P1': 8, 'P2': 5, 'P3': 3}
        return mapping.get(old_priority, 5)
    return int(old_priority)
```

## ⚠️ 常见问题

### 问题1: 执行unified_schema.sql报错 "Database exists"

**解决方案**:
```sql
-- 如果synapsetest数据库已存在，先删除
DROP DATABASE IF EXISTS synapsetest;

-- 然后重新执行
source database/unified_schema.sql;
```

### 问题2: Backend启动失败 "Unknown database 'test_management'"

**原因**: application.yml还在使用旧数据库名

**解决方案**:
确认 `backend/src/main/resources/application.yml` 已修改为:
```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/synapsetest
```

### 问题3: AI-Service报错 "Table 'synapsetest.test_cases' doesn't exist"

**原因**: 可能MySQL客户端还在使用旧版本

**解决方案**:
```bash
# 确认使用正确的mysql_client.py
cd ai-service/data
ls -la mysql_client*.py

# 应该只有mysql_client.py和备份文件
# 确保mysql_client.py中使用Backend的test_cases表结构
```

### 问题4: 优先级字段类型不匹配

**错误信息**: `Data truncated for column 'priority'`

**原因**: 代码还在使用 'P0', 'P1' 字符串

**解决方案**:
在AI-Service的代码中添加优先级转换:
```python
# ai-service/data/mysql_client.py
def save_test_case(self, test_case):
    priority = self._convert_priority(test_case.get('priority', 5))
    # ... 使用转换后的priority
```

### 问题5: 外键约束错误

**错误信息**: `Cannot add or update a child row: a foreign key constraint fails`

**原因**: 尝试插入的environment_id或version_id不存在

**解决方案**:
```sql
-- 先插入测试环境和版本
INSERT INTO test_environments (id, name, status) VALUES ('env-dev', 'DEV', 'AVAILABLE');
INSERT INTO test_versions (id, name, product_version) VALUES ('ver-1.0', 'v1.0', '1.0.0');

-- 然后再插入推荐历史
INSERT INTO recommendation_history (..., environment_id, version_id)
VALUES (..., 'env-dev', 'ver-1.0');
```
