## 🔍 常见问题

### Q1: 为什么从策略推荐跳转后，任务名称是"xxx - AI推荐"？

**A**: 这是为了标识该任务是基于AI推荐创建的，便于追踪和统计。您可以自由修改任务名称。

### Q2: 跳转后的数据可以修改吗？

**A**: 当然可以！所有预填的数据都只是建议值，您可以根据实际需求调整任何字段。

### Q3: 如果刷新页面，预填的数据会消失吗？

**A**: 会的。这是设计行为，避免刷新后重复应用推荐。如果需要保留，建议在刷新前完成创建。

### Q4: 策略推荐页面的下拉列表为空怎么办？

**A**: 可能的原因：
1. 数据库中没有数据 → 先添加测试环境、版本、用例
2. 后端服务未启动 → 检查后端服务
3. API 请求失败 → 查看浏览器控制台错误

**解决方案**:
```bash
# 检查数据库
mysql -u root -p synapsetest -e "SELECT COUNT(*) FROM test_environments;"
mysql -u root -p synapsetest -e "SELECT COUNT(*) FROM test_versions;"
mysql -u root -p synapsetest -e "SELECT DISTINCT module FROM test_cases WHERE module IS NOT NULL;"
```

### Q5: 两个页面的字段名不完全一样？

**A**: 这是有意设计的：

**策略推荐**:
- 任务标识（taskId）- 可以是描述性名称
- 变更模块（modules）- 强调代码变更

**创建任务**:
- 任务名称（taskName）- 正式的任务名称
- 测试模块（modules）- 强调测试范围

但在传递数据时会自动转换，用户无感知。
