# 前端UI设计方案

## 一、整体设计理念

### 1.1 设计原则
- **简洁高效**：操作路径短，减少用户思考时间
- **智能引导**：AI能力前置，智能推荐贯穿始终
- **数据可视**：关键指标可视化，一目了然
- **响应式设计**：支持PC、平板等多端访问

### 1.2 视觉风格
- **主色调**：科技蓝（#1890FF）- 体现AI科技感
- **辅助色**：成功绿（#52C41A）、警告橙（#FA8C16）、错误红（#F5222D）
- **中性色**：深灰（#262626）、浅灰（#F0F0F0）、白色（#FFFFFF）
- **字体**：思源黑体/Roboto
